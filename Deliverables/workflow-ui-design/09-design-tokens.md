## Design Tokens (Microsoft Fluent Design System)

| Token | Value | Use |
|-------|-------|-----|
| Brand Blue | `#0078D4` | Toggle active state, links |
| Learning Green | `#107C10` | Learning Mode badge, primary CTA |
| Cue Yellow | `#FCE100` | 🟡 behaviour-triggered cue dots |
| Cue Green | `#107C10` | 🟢 scheduled cue dots |
| Surface | `#F2F2F2` | Answer Mode background |
| Learning Surface | `#E8F4E8` | Learning Mode background |
| Profile Banner | `#FFF4CE` | Profile-adaptive banner background |
| Text Primary | `#323130` | Body text |
| Text Secondary | `#605E5C` | Labels, hints, secondary actions |
| White | `#FFFFFF` | Cards, input fields |

**Typography (Segoe UI):**
- Heading: Segoe UI Semibold 18px
- Body: Segoe UI Regular 14px
- Cue type label: Segoe UI Bold 11px, uppercase, letter-spacing 0.5px
- Citation footnote: Segoe UI Italic 10px
