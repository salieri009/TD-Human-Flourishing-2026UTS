# TD Assignment 3 — Shaping Technologies That Shape Us

## About

This repo contains the group submission for TD Assignment 3. The project looks at how generative AI affects student thinking, critical thinking, and learning, then turns that into a short presentation and briefing document for Microsoft Education.

## Project Files

- `Presentation/`: Canva slide export
- `Deliverables/`: briefing document, slide notes, and UI/workflow notes
- `Research/`: source PDFs used for reading and citation only
